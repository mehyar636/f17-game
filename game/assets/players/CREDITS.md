# Player assets

- **Player model, textures and locomotion / cheering motion capture**: Microsoft Rocketbox Avatar Library
  (https://github.com/microsoft/Microsoft-Rocketbox), MIT licence — see LICENSE.md.
- **Football kick motion capture**: CMU Graphics Lab Motion Capture Database, subjects 10 and 11.
  The data used in this project was obtained from mocap.cs.cmu.edu.
  The database was created with funding from NSF EIA-0196217.
